# Закон Бенфорда — сайт-инструмент

Готовый сайт для проверки чисел на соответствие закону Бенфорда. Файл `index.html` — это весь сайт целиком (один файл, ничего дополнительно ставить не нужно).

## Как выложить на GitHub Pages (бесплатно, свой адрес, работает всегда)

1. Зайдите на [github.com](https://github.com) и войдите в аккаунт (если его нет, зарегистрируйтесь: это бесплатно и займёт пару минут).
2. Нажмите зелёную кнопку **New** (или **+** в правом верхнем углу → **New repository**).
3. В поле **Repository name** впишите короткое имя, например `zakon-benforda` (можно с вашей фамилией: `zakon-benforda-mazhaeva`). Отметьте **Public**. Кнопку **Add a README file** можно не трогать. Нажмите **Create repository**.
4. На странице репозитория нажмите **Add file → Upload files**.
5. Перетащите в окно браузера файл `index.html` из этого архива (можно и `README.md`, это не обязательно). Внизу нажмите **Commit changes**.
6. Перейдите на вкладку **Settings** репозитория (сверху) → в меню слева выберите **Pages**.
7. В разделе **Build and deployment → Branch** выберите `main` и папку `/ (root)`, нажмите **Save**.
8. Подождите одну-две минуты и обновите страницу: сверху появится зелёная плашка со ссылкой вида:

   `https://ваш-логин.github.io/zakon-benforda/`

Это и есть постоянная ссылка на сайт — она не зависит от Claude, открывается у кого угодно без входа в какой-либо аккаунт и работает всегда, пока существует репозиторий. Имя в этой ссылке (`zakon-benforda` или как вы назвали репозиторий на шаге 3) — то, что раньше нельзя было изменить в ссылке на claude.ai, здесь вы его выбираете сами.

## Если нужно что-то поправить в сайте после публикации

Откройте файл `index.html` прямо на GitHub (нажмите на него в списке файлов репозитория), нажмите на иконку карандаша (**Edit**), внесите правки и нажмите **Commit changes**. Через минуту-две обновлённая версия появится по той же ссылке.

## Что внутри архива

- `index.html` — код сайта, уже готовый к загрузке на GitHub Pages.
- `README.md` — этот файл с инструкцией.
